+ registration_metrics.py
+ + See TODO # 1 (these functions are all relevant)
+ + NOTE: Added Functions
+ + + compute_ncc(), compute_ssim(), compute_mse(), compute_rmse(), compute_residual_motion(),
+ + + compute_mutual_information(), compute_sharpness_fraction(), summarize_metrics()
+ + [compute_ncc]
+ + + Normalized cross‐correlation of each frame against the reference. ref: 2D (H×W), frames: 3D (T×H×W) → returns (T,)
+ + [compute_ssim]
+ + + Structural Similarity Index (SSIM) per frame.
+ + [compute_mse]
+ + + Pixel‐wise mean squared error per frame.
+ + [compute_rmse]
+ + [compute_residual_motion]
+ + + Frame‐to‐frame RMS difference: sqrt(mean((f[t]−f[t−1])²)). Returns length T−1.
+ + [compute_mutual_information]
+ + + Normalized mutual information between ref and each frame.
+ + [compute_sharpness_fraction]
+ + + Fraction of pixels whose Laplacian magnitude > thresh. A basic sharpness proxy.
+ + [summarize_metrics]
+ + + Compute all blind quality metrics before vs. after registration.

+ utils.py
+ + NOTE: Added Functions
+ + + find_git_root(), aggregate_profiler_metrics(),
+ + + estimate_ref_gpu_memory_bytes(), max_safe_nt_chunk(), required_vram_for_nt(), bytes_gib(),
+ + + estimate_ref3d_vram_bytes_per_batch(), and choose_gpu_reference_batch_size()
+ + NOTE: These functions are used to implement benchmarking and determining a priori optimal memory parameter settings
        The function in the first line are in use, the rest are not yet being used
+ + [find_git_root]
+ + + Walks up from start_path (or the current file’s directory) until it finds a folder containing ".git". Returns the
+ + + absolute path to that folder, or raises if none is found.
+ + [aggregate_profiler_metrics]
+ + + Aggregates per-iteration profiler metrics from combo_* subdirectories.
+ + [estimate_ref_gpu_memory_bytes]
+ + + Estimates GPU bytes needed during 3D rigid FFT/phase-correlation for a chunk of nt timepoints (batch), nz planes,
+ + + ny*nx pixels. Default assumes float64 (8 bytes) and ~2 large arrays live at once (e.g., the phase-corr/FFT work
+ + + buffer + one other large buffer). Adjust `live_buffers` if your call site clearly holds more/fewer.
+ + [max_safe_nt_chunk]
+ + + Computes a safe upper bound for gpu_reference_batch_size (nt_chunk).
+ + [required_vram_for_nt]
+ + + A convenience wrapper to report required bytes for a desired nt.
+ + [bytes_gib]
+ + [estimate_ref3d_vram_bytes_per_batch]
+ + + Returns a function f(nt) -> estimated VRAM bytes for a given time-batch (nt) during rigid_3d_ref_gpu() / reg_3d_gpu().
+ + + Heuristic components (per batch): 1) mov batch (complex64 for FFT): nz*nt*ny*nx*complex_bytes 2) one or two extra
+ + + FFT work buffers of similar size and 3) mask/filter buffers and phase-corr scratch of similar scale. We gather
+ + + these with a conservative safety multiplier.
+ + [choose_gpu_reference_batch_size]
+ + + Pick a batch size (nt) for reference-building that should fit in available VRAM.
